Curvature is a measure of how much a geometric object deviates from being flat. - Ricci curvature does this by tracking how nearby geodesics converge or diverge. - A discrete version of it, the Ollivier-Ricci curvature, can be defined on graphs using optimal transport theory. ] .simple-row[ .width-80[ ![](/assets/csi-presentation-2026/surface_and_graph.png) ] ] .font-xxs[ credits image: https://arxiv.org/abs/2508.11390 ] --- ### The Discrete Ricci flow (it converges!) .font-sm[ - .nord14[Simplicial complex]: a collection of simplices (points, edges, triangles, etc.); it helps approximate the underlying shape of a dataset - .nord14[Betti numbers]: topological invariants that count the number of connected components, holes, and voids in a simplicial complex - .nord14[Filtration]: a nested sequence of simplicial complexes that captures the evolution of topological features across different scales .simple-row[ .width-80[ ![](/assets/csi-presentation-2026/filtration.png) ] ] .center.font-xs[ Example of Filtration ] .font-xxs[ credits image: https://arxiv.org/pdf/2302.09826v4 ] --- ### Filtration and Persistence diagrams .simple-row[ .width-100[ ![](/assets/csi-presentation-2026/tda_pipeline.png) ] ] .center.font-xs[ Classical pipeline of TDA: from a point cloud to a persistence diagram ] At the end of the filtration, the persistence diagram contains features and information about the data that can be used by an ML pipeline. .font-xxs[ credits image: https://geometrica.saclay.inria.fr/team/Fred.Chazal/slides/Persistence2025_v24nov2025.pdf ] --- ### HMM on filtration data Graph classification can be done using HMM on the persistence data obtained from the filtration. -
